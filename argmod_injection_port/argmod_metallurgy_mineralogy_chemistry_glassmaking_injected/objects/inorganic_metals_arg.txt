==vanilla edited, built off Haethei and Putnam, plus own ==
==tried to use reported values where found. When not found, shear = 0.6 x tensile and compressive = 1.2 x tensile for steels and bronzes and x1 or <x1 for materials known to be more ductile like copper and brass==
==compressive 1.2 x tensile deviates greatly from DF's default compressive 3.5 x tensile, but for IRL metals it's never that high. ==
==impact yield and fracture should also not be 3.5 x tensile, but this is now expected for game balance. Armor get wrecked if this is reduced; maybe periodically purging xXarmorXx has its own appeal, but this mod is bloated enough==
==impact yield and impact fracture, when measured in MPa, are more akin to dynamic yield and dynamic strength. Simplified, should be pushing 2.0 x tensile for really springy steels, and lower multipliers for bronzes, hardened steels, etc==
