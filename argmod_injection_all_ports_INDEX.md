Other modders' mods ported to Refinish Metal's module engine. Each mod folder below is a complete DF mod: its `data/` JSON is what RM's module engine injects at runtime, and its `objects/` and `graphics/` are ordinary raws that DF loads as usual. Injected content is not part of worldgen, so anything worldgen or another raw file needs stays in raws, and the port notes say what stayed and why.

## How to use this

Start with a port's notes: they record what moved, what stayed in raws and why, and the bugs found in the source mod. The JSON is RM's module schema at scale, so it is also where to find a worked example of a reagent, product or permission form. Search it by key:

```
grep -rn '"key": "IRIDIUM"' --include='*.json' .
```
